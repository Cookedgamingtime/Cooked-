# Cooked

An Android app that tracks your real game time and roasts you about it.

- Real game time via UsageStatsManager
- Meme-style "Cooked units" (minutes displayed as hours)
- Tiered hostile roasts based on how much you actually played
- A compliment after every roast so it doesn't hurt too much
- Daily notification via WorkManager
- Room database for session history
- Material 3, dark mode, Jetpack Compose

Build status: check the Actions tab.
